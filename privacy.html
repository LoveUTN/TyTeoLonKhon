Tý Tẹo Lớn Khôn Publisher

Privacy Policy

Last updated: October 30, 2026

Tý Tẹo Lớn Khôn Publisher ("the tool", "we") is an internal tool operated by Tý Tẹo Lớn Khôn. It uploads the operator's own videos to the operator's own YouTube channel and Facebook Page. It is used only by the channel owner and does not collect data from the public.

Use of YouTube API Services

The tool uses the YouTube API Services to upload videos. By using the tool, you agree to be bound by the YouTube Terms of Service. Google's collection and use of data is governed by the Google Privacy Policy.

Data we access, store and use

DataWhyWhere it is kept
Google OAuth refresh token with the youtube.upload scope To upload videos to the channel owner's YouTube channel without signing in each time Encrypted secret storage on the operator's own server. Never in source code or public repositories
Short-lived access tokens To authorize each upload request In memory only, discarded after use
Video files and metadata (title, description, tags, visibility) To create the video on YouTube and Facebook Provided by the operator; kept on the operator's server until the upload finishes
Uploaded video IDs To keep a log of what has been published Operator's server
Facebook Page access token To publish posts and videos to the operator's own Facebook Page Encrypted secret storage on the operator's own server

The tool does not access or store YouTube comments, analytics, subscriber lists, watch history, or any information about other YouTube or Facebook users. It does not read the Google account's email, contacts or any data outside the permission listed above.

How data is shared

Data is sent only to Google (YouTube Data API) and Meta (Graph API) for the sole purpose of publishing the operator's videos. We do not sell, rent or share data with any other third party, and we do not use it for advertising.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies and device storage

The tool has no public website features and places no cookies or tracking technologies on users' devices. During the one-time authorization, Google's sign-in page may use its own cookies, as described in the Google Privacy Policy.

Revoking access

The channel owner can revoke the tool's access to YouTube at any time on the Google security settings page. Access to Facebook can be removed in Facebook Settings under Business Integrations. Once access is revoked, the stored token stops working and the tool can no longer upload anything.

Data retention and deletion

  • Refresh tokens are kept until access is revoked or the tool is retired, then deleted from storage.
  • Temporary video files are deleted after the upload finishes.
  • Upload logs are kept for up to 12 months and then deleted.

To request deletion of any stored data, email thanhtung.mobiledev@gmail.com. We will delete it within 30 days. Videos already published stay on YouTube and Facebook and can be removed in YouTube Studio or on the Facebook Page.

Security

Tokens are stored encrypted, access to the server is limited to the operator, and all API traffic uses HTTPS.

Children

Although the channel's videos are made for children and their parents, the tool itself is not directed at children and is used only by the adult channel owner. It does not collect any data from viewers of the channel, whether children or adults.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
